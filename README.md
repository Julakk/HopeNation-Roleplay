# HopeNation-Roleplay

Modern & Lightweight Roleplay Gamemode (open.mp)

## Setup
1. Salin `server.cfg.example` jadi `server.cfg`
2. Ganti `rcon_password` dengan password sendiri
3. Compile `gamemodes/hopecity.pwn` jadi `hopecity.amx`
4. Jalankan server

## Struktur
- `gamemodes/` : source gamemode
- `deploy/` : script deploy
- `tools/` : tools bantu
- `server.cfg.example` : template config (`server.cfg` asli tidak di-commit)
